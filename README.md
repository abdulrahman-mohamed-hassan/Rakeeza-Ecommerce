# Rakeeza – Full-Stack E-commerce Website

## Overview
Full-stack e-commerce website for furniture store built with PHP and MySQL.

## Features
- User Registration & Login (password hashing)
- Product browsing with categories
- Search products with autocomplete
- Shopping Cart (add, update, remove)
- Wishlist (save favorite products)
- Checkout with OTP email verification
- Order confirmation emails
- Admin panel with dashboard, product/category/order management
- CSV Import/Export for bulk products

## Database Schema
- 7+ tables (users, products, categories, orders, order_items, wishlist, product_images)
- Foreign key constraints

## Technologies
- **Backend:** PHP (Procedural)
- **Database:** MySQL
- **Frontend:** HTML5, CSS3, JavaScript, Bootstrap 5
- **Email:** PHPMailer (SMTP)
- **QR Code:** QR Code API
